## 1. 摘要

doc-tutorial-guide 規範讓第一次操作的人從頭照做、完成部署、環境設定或接手既有系統的教學文件。它假設讀者不熟悉環境，每個位置、權限、畫面、預期結果都要寫出來。它擴充 doc-general-guide，衝突時以本 guide 為準。步驟以 GUI 管理工具的點選為主，等效指令作為替代；沒有 GUI 時允許只有指令的步驟。

使用順序：

1. 依 §0 確認文件屬於教學，而非 SOP、終端使用者手冊、README 或盤點清單。
2. 依父層 §1 蒐集素材，以真實管理工具畫面、設定、原始碼驗證標籤、選單路徑、狀態碼、錯誤訊息（§2）。
3. 文件以一行範圍聲明開頭；每個操作節依序寫：名稱優先標題 → 標籤為「操作條件」的前提 callout（有放置物或依賴條件時）→ 步驟（關鍵設定附簡短「為什麼」）→ 每個驗證點後的結果表（§3–§7）。
4. 以 §8 檢查清單收尾。

## 3. 其他

- **父層章節存在性**：§1 Inherited 與 Overrides 表引用的 §1、§2.1、§2.2、§2.5、§2.6、§2.7、§2.9–2.10、§2.11、§2.12、§2.13–§2.18、§3、§4、§5、§7，以及 §0 與 description 引用的 §0.1，皆存在於 doc-general-guide 1.2，內容與引用描述相符。
- **§0 邊界表缺 API 文件列**：description 列出不適用於 API 文件（`doc-openapi-guide`），§0 的鄰近類型表只有 SOP、終端使用者手冊、README、盤點清單四列。
- **步驟是否編號未明寫**：E22 覆寫父層 §2.2 時只改了「步驟單位與 code block」，沒有說教學步驟是否仍為編號清單；§5 與 §8 也未提編號。
- **服務概覽與盤點資料的界線未明寫**：E9 允許「任何服務或埠的概覽」用表格放在教學內，E7 規定盤點資料永不放進教學；doc-sop-guide 有一句區分（SOP 內的清單表只服務本文件步驟），本 skill 沒有對應說明。
- **用語未定義**：「關鍵設定」（§6）與「驗證點」（§3、§7）沒有判斷依據，由撰寫者自行判斷。
- **UI 路徑範例的語言**：§5 的 UI 路徑範例標明是中文文件的寫法（『』「」），連接詞卻是英文 `, then click`；父層 §2.14 要求單一語言，範例中這段連接詞該如何呈現沒有說明。
