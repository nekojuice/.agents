# manager 可修改 skill 本文

- Status: accepted
- Scope: 本 repo
- Date: 2026-10-19
- Authority: 使用者明確指示

## Decision

orchestrator-pm 的「不實作產品」規則針對程式實作。本 repo 的產品是 skill 文字，skill 修改不屬程式實作，因此由 manager session 在討論完成、使用者核可待沖入稿後直接寫入 skill 本文，不需另開 factory。

## How to apply

- 修改前先有 run 內的待沖入稿，並取得使用者對該稿的核可。
- 寫入時遵守 `create-skill-guide` 與專案中立規則。
- 寫入 skill 本文以外的程式或設定，仍依一般 PM 邊界處理。
