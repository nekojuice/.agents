## 1. 摘要

doc-readme-guide 規範私有或小團隊 repo 的 README.md，是 doc-general-guide 的 README 專用擴充，衝突時以本 guide 為準。README 為隊友與協作者回答「這是什麼、為何存在、長什麼樣子」，擁有操作文件推過來的架構與理由，但必須簡短易讀；用平實常見用語、不造詞、單一語言。

使用順序：

1. 依 §0 的 Inherited 與 Overrides 表確認哪些父層規則適用。
2. 依父層 §1 由淺入深理解專案，版本、路徑、結構以真實 manifest 與目錄樹驗證（§1）。
3. 依固定區塊順序撰寫九個區塊，選用區塊不適用時整塊省略（§2），各區塊依 §3 規則填寫。
4. 修訂既有 README 依 §4；省略開源社群區塊與逐端點 API 說明（§5）；遵守用詞、語言、識別資訊規則（§6）。
5. 以 §7 檢查清單收尾。
