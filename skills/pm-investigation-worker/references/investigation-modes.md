# Investigation Modes

## Question lookup

Locate the authoritative answer in current project sources. Return the answer, source, scope, and any qualification.

## Suspected bug trace

Establish expected behavior, reported or observed behavior, relevant execution path, plausible cause, contradictions, and missing reproduction evidence.

## Coverage audit

Map one desired capability to specification, implementation, verification, factory, and human-acceptance evidence. Identify absent or ambiguous links.

## Legacy comparison

Compare one bounded legacy behavior or data rule with the current target system. Do not assume every legacy behavior must be preserved.

## Gap search

Search one defined area for missing, incomplete, contradictory, or unverified project outcomes. Report candidates; do not create canonical cases.

## Document or rule decomposition

Break one defined document or rule set (for example a skill, a convention, or a guideline) into a summary, elements, conflicts, and gaps. Do not judge delivery completion, create cases, or edit the decomposed object.

Select one primary mode per assignment. Report adjacent discoveries as out of scope.
