## 1. 摘要

doc-general-guide 是「給人讀的文件」家族的基底與路由。讀者涵蓋工程師、操作者、API 呼叫者、應用程式使用者。它先決定文件類型，再載入負責該類型的子 skill：README、SOP／cheat-sheet／runbook、終端使用者操作手冊、教學、OpenAPI 文件各有子 skill；工程參考手冊與盤點／稽核清單由本 guide 直接負責。它也持有各子 skill 繼承或明確覆寫的共通規則。預設風格是指令導向，以畫面操作或程式註解為主的子 skill 會覆寫。

使用順序：

1. 依 §0 決定文件類型並載入負責的 skill；盤點／稽核清單依 §0.1。
2. 依 §1 由淺入深蒐集素材：既有 SOP → openspec 主 spec → openspec `changes/` → 原始碼進入點 → 設定檔，再依驗證規則只寫已定案狀態。
3. 依 §2 寫作硬規則、§3 標題命名、§4 括號規則、§5 code block 註解格式撰寫。
4. 子 skill 依 §6 的繼承方式標示差異；本 guide 負責的類型以 §7 檢查清單收尾。
